# StayOS Mobile Operations Incident Escalation Matrix

## 1. On-Call Escalation Paths

```
Incident Trigger (Crash / Connectivity / Auth Failure)
        │
Front-Desk / Duty Manager logs incident
        │
Level 1: System Admin reviews API logs & Neon database metrics
        │
Level 2: Lead Mobile Engineer triages Android Hermes crash reports
        │
Level 3: Database & Security Lead executes Point-in-Time Recovery if needed
```
