# StayOS Mobile Kitchen Display System (KDS) Specification

## 1. Scope & Overview
Dedicated high-contrast, large touch-target Kitchen Display System designed for Android tablets and kitchen wall stations.

---

## 2. KOT Lifecycle States
1. `Pending`: New order ticket placed by restaurant/waiter.
2. `Preparing`: Cook accepts ticket and begins food preparation.
3. `Ready`: Cook marks dish completed on the pass counter for pickup.
4. `Delivered`: Waiter serves the order to the dining table or guest room.
5. `Completed`: Order settled and finalized.
