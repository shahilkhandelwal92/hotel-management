# StayOS Android Device Provisioning & Setup Guide

## 1. Prerequisites
* Physical Android smartphone or tablet running Android 11.0 (API Level 30) or higher.
* Stable Wi-Fi or 4G/5G cellular internet connectivity.
* Access to `https://pms.stayos.com`.

---

## 2. Installation Steps
1. Transfer the signed release APK (`StayOS-Operations-v1.0.1.apk`) to the device via USB, MDM, or internal portal.
2. Tap the APK file $\rightarrow$ accept installation prompt ("Install from unknown sources" if installing via file manager).
3. Open **StayOS Operations** from the application drawer.
4. Input assigned staff email and password $\rightarrow$ Tap **Sign In**.
5. Select active property if assigned to multiple properties.
